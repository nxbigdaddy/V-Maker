# GUI 与交互设计

## 1. 总体布局

建议使用桌面工作台布局：

```text
┌──────────────── 顶部：项目 / 保存 / 预算 / 运行 / 导出 ────────────────┐
│ 左侧导航        │ 中央主工作区                         │ 右侧属性检查器 │
│ 项目概览        │ 文档、卡片、画布、故事板或时间线      │ 当前对象配置   │
│ 故事与剧本      │                                      │ 版本/质检/提示词│
│ 项目圣经        ├──────────────────────────────────────┤               │
│ 分镜            │ 底部任务中心：队列、日志、费用、错误  │               │
│ 素材库          │                                      │               │
│ 时间线          │                                      │               │
│ 导出            │                                      │               │
└───────────────────────────────────────────────────────────────────────┘
```

UI 不直接暴露复杂 API 调用；高级参数放在可折叠面板。

## 2. 首次创建向导

### 步骤 1：故事

- 粘贴或导入故事；
- 识别语言；
- 选择单集或“由 AI 建议分集”；
- 可补充一句创作意图。

### 步骤 2：成片目标

- 横屏/竖屏；
- 时长；
- 受众；
- 视觉风格模板；
- 对白/旁白；
- 输出 MP4、剪映草稿或两者。

### 步骤 3：生产策略

- 草稿、标准、专业模式；
- 质量/速度/成本滑杆；
- 项目预算硬上限；
- 选择默认模型组合。

### 步骤 4：计划预览

展示预计：

- 集数、场景数、镜头数；
- 图片/视频/语音调用数量；
- 时间和费用区间；
- 审核节点。

确认后创建项目，但允许稍后修改。

## 3. 项目首页（导演控制台）

首页回答四个问题：

1. 当前做到哪一步；
2. 哪些任务正在执行；
3. 哪些内容需要用户确认；
4. 已花多少钱、预计还要多少。

建议组件：

- 制作阶段进度条；
- 集数卡片；
- “待我审核”队列；
- 最近生成结果；
- 异常任务；
- 成本仪表；
- 主操作按钮：`继续自动制作`。

## 4. 故事与剧本页

### 4.1 三栏结构

- 左：集/场景树；
- 中：大纲或剧本编辑器；
- 右：人物、地点、时长和改写建议。

### 4.2 操作

- 让 AI 缩短、扩写、儿童化、增强冲突；
- 将选中文本拆为场景；
- 锁定台词；
- 查看版本差异；
- 检查预估时长；
- “批准并生成分镜”。

## 5. 项目圣经页

页签包括：

- 风格；
- 角色；
- 场景；
- 道具；
- 声音；
- 世界观规则。

### 角色详情

- 主参考图；
- 正侧背三视图；
- 表情和动作；
- 固定外观描述；
- 禁止变化项；
- 声线；
- 出现在哪些集和镜头；
- `锁定角色` 开关。

变更已使用的资产时弹出影响提示：

> 此修改影响 3 集、27 个镜头。仅用于新镜头，还是创建新版本并重新生成受影响镜头？

## 6. 分镜工作台

提供三种视图：

### 6.1 卡片视图

适合浏览故事节奏。每张卡显示：

- 缩略图；
- 镜头编号和时长；
- 景别、机位、运镜；
- 出场角色；
- 动作和对白；
- 制作策略；
- 状态与质检分数。

### 6.2 表格视图

适合批量编辑和筛选。支持按场景、角色、状态、复杂度、模型和成本筛选。

### 6.3 故事板视图

拖拽排序，播放动态分镜，显示音频波形和字幕。

### 镜头详情抽屉

包含：

- 剧情目的；
- 构图和连续性；
- 关键帧候选；
- 视频候选；
- 提示词（基础层、资产层、镜头层）；
- 生成参数；
- 质检结果；
- 版本历史；
- 自然语言修改框。

## 7. 素材库

目录与标签并存：

- 图片、视频、音频、字幕、项目文件；
- 按角色、场景、道具、集、场、镜头筛选；
- 显示使用位置；
- 支持本地素材拖入；
- 设置为参考、候选、已批准或已弃用；
- 禁止直接覆盖已被时间线引用的文件，替换应创建新版本。

## 8. 时间线页

建议首版实现轻量多轨时间线，而非完整 NLE。

轨道：

- V1 主视频；
- V2 叠加/特效；
- A1 对白；
- A2 音效；
- A3 音乐；
- S1 字幕。

支持：

- 播放、定位、缩放；
- 调整片段入点/出点；
- 镜头重排；
- 音量和淡入淡出；
- 字幕文本和时间调整；
- 简单转场；
- 重新合成代理预览。

复杂调色和高级特效交给外部 NLE。

## 9. 任务中心

任务中心必须对普通用户友好：

- 队列中、运行中、等待回调、成功、失败、暂停、取消；
- 任务类型和所属镜头；
- 当前尝试次数；
- 预计/实际费用；
- 错误的人类可读解释；
- 重试、更换模型、降低质量、使用保底方案。

不得只显示 Provider 原始报错。

## 10. 导出向导

### 页面一：输出类型

- 合成视频；
- 剪映草稿；
- 两者；
- 通用时间线包。

### 页面二：规格

- 分辨率、帧率、编码；
- 字幕烧录或独立 SRT；
- 是否包含水印；
- 是否导出分轨音频；
- 是否复制全部媒体到交付目录。

### 页面三：兼容性检查

- 缺失素材；
- 时间线空洞；
- 片段帧率冲突；
- 剪映版本兼容性；
- 磁盘空间。

### 页面四：结果

- 打开输出位置；
- 播放成片；
- 查看导出报告；
- 若剪映草稿失败，提供 XML/EDL/素材包降级方案。

## 11. 全局自然语言助手

右下角助手理解当前上下文，例如：

- “把第 3 场变得紧张一些”；
- “不要改台词，只缩短镜头”；
- “将所有白骨精镜头改用候选图 B”；
- “只重做质检低于 75 分的视频”；
- “预算还剩多少？”

执行批量修改前必须展示变更预览与预计费用。

## 12. 关键 UX 原则

- 自动生成不等于自动批准；
- 高成本操作二次确认并显示估价；
- 删除优先软删除；
- 每个阶段提供“撤销到上一批准版本”；
- 状态名称面向创作者，而不是面向开发者；
- 默认隐藏 seed、采样器等高级字段；
- 对长任务使用后台队列，GUI 不阻塞；
- 所有失败都应给出可执行的下一步。
