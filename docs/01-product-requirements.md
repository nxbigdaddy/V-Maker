# 产品需求与范围

## 1. 产品愿景

用户提供一段故事、分集大纲或完整剧本，V-Maker 自动组织并调用文本、图像、视频、语音和合成工具，生成可审阅、可修改、可追溯的动画项目。

系统追求的不是“完全不可见的一键黑盒”，而是：

- 新手可以一键生成；
- 创作者可以在关键节点确认；
- 专业用户可以深入到场景、镜头和素材版本进行控制。

## 2. 目标用户

### 2.1 个人创作者

希望用少量配置快速生成 30 秒至 5 分钟短片。

### 2.2 短剧与动画小团队

需要多人审阅、统一角色与风格、控制成本并连续生产多集。

### 2.3 IP 内容方

拥有故事或人物设定，希望批量生成样片、动态分镜或系列内容。

## 3. 输入

### 3.1 内容输入

- 直接粘贴故事文本；
- 导入 TXT、Markdown；
- 后续支持 DOCX、PDF；
- 导入已有剧本或分集大纲；
- 导入角色、场景、道具参考图；
- 导入已有音频、音乐和视频素材。

### 3.2 项目参数

- 单集/多集；
- 目标总时长或单集时长；
- 画幅：16:9、9:16、1:1、自定义；
- 分辨率和帧率；
- 目标观众与内容分级；
- 画面风格；
- 语言、旁白和对白偏好；
- 自动化模式；
- 质量、速度和预算上限。

## 4. 输出

### 4.1 生产文档

- 故事分析；
- 项目圣经；
- 分集大纲；
- 文学剧本；
- 分镜脚本；
- 镜头清单；
- 资产清单；
- 成本和任务报告。

### 4.2 媒体输出

- 角色、场景、道具设定图；
- 故事板和动态分镜；
- 镜头视频；
- 人声、音乐、音效、字幕；
- 合成 MP4/MOV；
- 无字幕版、纯净版、音轨分离版；
- 剪映草稿或通用时间线交换包。

## 5. 三种工作模式

### 5.1 草稿模式

- 尽可能自动；
- 使用低成本模型和较低分辨率；
- 自动接受达到最低分数的结果；
- 失败时优先降级为静态图加运镜；
- 适合创意验证。

### 5.2 标准模式（默认）

保留四个确认点：

1. 分集与大纲；
2. 项目圣经和角色外观；
3. 动态分镜；
4. 最终成片。

### 5.3 专业模式

- 用户可编辑所有结构化字段；
- 每场景或每镜头审核；
- 可锁定资产与版本；
- 可指定模型、参考图、提示词和生成参数；
- 可手工替换任何生成素材。

## 6. 核心功能

### 6.1 项目管理

- 新建、复制、归档和删除项目；
- 项目自动保存和恢复；
- 单集/多集状态总览；
- 项目模板；
- 项目导入导出。

### 6.2 故事开发

- 故事理解与结构化；
- 自动分集；
- 目标时长约束；
- 剧本和对白生成；
- 自然语言修改；
- 版本比较和回滚。

### 6.3 一致性资产库

- 角色、场景、道具、风格、声音；
- 参考图和提示词模板；
- 资产锁定；
- 系列项目复用；
- 变更影响分析。

### 6.4 分镜与时间线

- 自动拆镜头；
- 镜头卡片和表格视图；
- 故事板拖拽排序；
- 动态分镜预览；
- 多轨时间线；
- 镜头级重生、替换和裁切。

### 6.5 生成与审核

- 图像、视频、语音、音乐任务；
- 批量生成与并发限制；
- 自动质检；
- 失败重试与降级；
- 版本候选对比；
- 审核通过/驳回/锁定。

### 6.6 成本控制

- 项目预算和单集预算；
- 每种 Provider 价格配置；
- 生成前预估；
- 实际花费追踪；
- 单任务最大重试次数；
- 达到阈值时暂停而非继续扣费。

## 7. 非功能需求

- 任务可中断、恢复、取消；
- 应用异常退出后不丢失任务状态；
- API 密钥加密保存；
- 大文件不写入数据库正文，只保存路径和元数据；
- 所有关键操作记录审计日志；
- 支持 Windows，后续考虑 macOS；
- UI 在数百镜头规模下仍可流畅使用；
- 同一任务重复回调应保持幂等；
- Provider 暂时故障时可退避重试。

## 8. 首版不做

- 自动生成影视级长篇动画；
- 复杂多人协作和云端权限体系；
- 自研图像或视频基础模型；
- 完整替代专业 NLE；
- 未经验证地承诺兼容所有剪映版本；
- 自动发布到所有内容平台；
- 完全无人监管的版权判断。

## 9. 成功指标

- 500–3000 字故事可生成 30–90 秒完整样片；
- 任一镜头可独立重做，不必全片重生；
- 用户能在一个 GUI 中完成所有核心步骤；
- 项目中每个媒体资产均可追溯到生成任务；
- 输出可播放成片；
- 至少一种目标剪映版本可导入草稿，失败时有通用时间线降级输出；
- 成本不超过用户设置的硬上限。
