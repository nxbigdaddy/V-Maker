# MVP 路线图与验收标准

## 1. MVP 目标

打通以下可运行闭环：

```text
500–3000 字故事
→ 剧本和项目圣经
→ 10–20 个镜头
→ 角色参考和关键帧
→ 镜头视频/TTS
→ 轻量时间线
→ 30–90 秒 MP4 + SRT
→ 限定版本剪映草稿实验导出
```

首版优先保证：可恢复、可追溯、可局部重做、不会无限消费 API。

## 2. P0 功能

- Windows 单用户桌面应用；
- 项目创建、打开、复制、归档；
- 单集/多集纯文本和 Markdown 导入；
- LLM 结构化故事、剧本和分镜；
- 项目圣经和角色/场景资产；
- 至少一个文本、生图、生视频、TTS Provider；
- 镜头级生成、候选选择和上传替换；
- 标准审核模式与自动模式；
- 持久化任务队列、取消、重试、恢复；
- 成本估计与硬预算；
- 基础自动质检；
- 动态分镜；
- 轻量多轨时间线；
- FFmpeg MP4、SRT 和分轨输出；
- 剪映基础草稿的版本限定适配；
- API Key 安全存储。

## 3. 分阶段实施

### M0：技术验证（1–2 周）

目标：验证最大风险，不做完整 UI。

- 调用选定 LLM 并通过 JSON Schema 获得分镜；
- 调用 Qwen Image 或实际选定生图 API；
- 调用 H3 或实际选定视频 API；
- 调用 TTS；
- FFmpeg 将 3–5 个镜头合成为 MP4；
- 获取目标剪映版本的合法测试草稿并验证最小可行写入；
- 记录真实 API 限制、费用和回调方式。

退出条件：能以脚本方式完成 15–30 秒样片，明确剪映适配是否可行。

### M1：项目骨架与数据底座（2–3 周）

- 桌面壳和本地 API；
- SQLite 迁移；
- 项目/集/场/镜头 CRUD；
- 资产与不可变版本；
- 本地项目目录；
- 密钥存储；
- 任务和事件表；
- 应用重启恢复。

退出条件：项目可保存、关闭、重新打开，任务与资产不丢失。

### M2：文本创作与项目圣经（2–3 周）

- 故事分析；
- 自动/手动分集；
- 剧本结构化；
- 角色、场景、道具和风格；
- 审核与版本；
- 分镜表和提示词编译基础。

退出条件：一段故事能稳定得到用户可编辑的结构化分镜。

### M3：媒体生成与任务中心（3–5 周）

- 生图、生视频、TTS 适配器；
- 异步提交、轮询和下载；
- 并发、限流、重试、取消；
- 候选资产和镜头级重生；
- 费用账本与预算；
- 基础硬规则质检。

退出条件：部分任务失败不影响其他镜头，重启后可以续跑。

### M4：动态分镜、时间线与 MP4（3–4 周）

- 临时配音；
- 自动组装时间线；
- 代理预览；
- 镜头排序和裁切；
- 字幕、人声、音乐和音效轨；
- FFmpeg 合成和输出验证。

退出条件：在 GUI 中从故事生成可播放的 30–90 秒成片。

### M5：剪映适配与打磨（2–4 周）

- 目标版本探测；
- 剪映能力矩阵；
- 媒体包；
- 基础轨道映射；
- 兼容性报告；
- Golden fixture 测试；
- 安装包、错误信息和清理策略。

退出条件：在明确支持的剪映 Windows 版本中可打开测试草稿；不支持项可降级并报告。

以上仅是产品级粗估，实际时间取决于团队人数、Provider 文档质量和剪映格式验证结果。

## 4. MVP 验收场景

### A. 多集导入

- 导入至少 3 集故事；
- 可修正自动拆集；
- 项目圣经由所有集共享。

### B. 一键样片

- 使用默认模板；
- 不配置高级模型参数；
- 从文本生成低清动态分镜和最终 MP4。

### C. 局部修改

修改一个镜头的对白后：

- 仅相关 TTS、字幕、必要的视频/口型和时间线变为过期；
- 不重做无关角色参考图和其他镜头。

### D. 错误恢复

- 一个视频任务失败，其他镜头继续；
- 可重试、换模型或使用静态运镜；
- 关闭并重开应用后状态正确。

### E. 成本控制

- 发起任务前展示估价；
- 到达软阈值提醒；
- 超过硬预算不再自动提交付费任务。

### F. 导出

- MP4 可播放；
- SRT 时间正确；
- 分轨音频长度正确；
- 剪映草稿在受支持版本打开；
- 导出报告列出所有降级和警告。

## 5. 可量化标准

- 端到端样片成功率 ≥ 80%（允许少量镜头降级）；
- 已完成任务在应用重启后的恢复率 ≥ 99%；
- 所有生成资产 100% 可追踪来源 task attempt；
- 预算硬上限违规调用为 0；
- 局部重做不会触发无依赖的任务；
- MP4 导出成功率 ≥ 95%；
- 目标剪映版本基础草稿打开率 ≥ 90%（测试夹具范围内）；
- GUI 中常规编辑响应 < 200ms，不含模型和渲染任务。

## 6. P1

- 多 Provider 智能路由；
- 视觉身份、一致性和视频闪烁评分；
- 词级字幕对齐与发音词典；
- 音频自动 ducking；
- 批量模板和跨项目资产库；
- ASS 字幕；
- FCPXML/EDL；
- 更丰富的时间线操作；
- 团队远程审核入口。

## 7. P2 / 暂缓

- 专业级 NLE；
- 多人实时协作；
- 模型训练和 LoRA 训练；
- 分布式 GPU 集群；
- 自动平台发布；
- 手机端完整编辑；
- 任意剪映版本完全兼容；
- 草稿反向导入和无损双向同步。

## 8. 开发优先级原则

按以下顺序取舍：

1. 数据不丢；
2. 费用不失控；
3. 局部可重跑；
4. 输出可复现；
5. 用户看得懂失败原因；
6. 一致性和画面质量；
7. Provider 数量；
8. 高级编辑功能。
