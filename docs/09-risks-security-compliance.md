# 风险、安全与合规

## 1. 产品与质量风险

### 1.1 “一键”期望过高

风险：用户期望输入长篇小说立即获得影视级成片。

措施：

- 明确质量档位；
- 先输出动态分镜；
- 显示需要人工审核的风险镜头；
- 为失败镜头提供降级；
- 首版限制时长和镜头数量。

### 1.2 角色一致性不足

措施：项目圣经、批准参考图、版本锁定、视觉 QC、短镜头、必要时引入 LoRA/3D 资产。

### 1.3 动作和多人互动失败

措施：分镜风险评分、拆短镜头、减少同镜头人物、使用合成或静态运镜保底。

### 1.4 模型升级导致结果漂移

措施：记录模型版本、模板版本和参数；项目可固定模型；升级前做回归样片。

## 2. 成本和供应商风险

- 费率变化；
- 余额不足；
- 限流；
- API 下线；
- 内容审核差异；
- 异步任务丢失。

措施：能力型 Provider 接口、价格配置、预算预留、重试上限、健康检查、主备路由和中立资产格式。

## 3. 数据安全

### API 密钥

- 存在 OS Keychain；
- UI 只显示掩码；
- 日志自动脱敏；
- 不随项目导出；
- 删除 Provider 时同时删除凭据引用。

### 用户内容

- 明确哪些内容会上传第三方；
- 可按 Provider 展示数据处理说明；
- 支持敏感项目禁用外部 Provider；
- 临时上传 URL 设置最短有效期；
- 本地项目目录权限遵循操作系统。

### 外部回调

- HTTPS；
- 验签；
- nonce/时间戳；
- 防重放；
- attempt 幂等；
- 不信任回调提供的文件名和 MIME。

## 4. 文件与执行安全

- 所有外部文件先写临时隔离目录；
- 检测真实 MIME 和可解码性；
- 限制最大尺寸和时长；
- 路径规范化，防止目录穿越；
- FFmpeg 使用 argv 数组，不拼 shell 命令；
- 导出不覆盖用户现有文件，除非明确确认；
- ZIP 解压限制文件数量、总大小和路径；
- 禁止执行 Provider 返回的脚本或指令。

## 5. 版权与许可

每个资产应记录：

- 来源；
- 作者/上传者；
- 生成 Provider；
- 模型和日期；
- 商用许可备注；
- 参考素材许可；
- 到期时间（如有）；
- 是否允许二次分发。

系统只能提示和记录，不应自动承诺用户拥有完整版权。

对《西游记》等公版作品：原著故事可能属于公共领域，但具体影视版角色造型、台词、音乐、演员肖像和声音仍可能受保护。

## 6. 肖像和声音克隆

- 声音克隆前要求记录授权；
- 保存用途和期限；
- 支持撤销并阻止新任务；
- 对真人参考图明确征得同意；
- 不默认提供名人声音/肖像模板；
- 输出可选 AI 生成标记。

## 7. 内容安全

安全检查在三个位置执行：

1. 故事和提示词提交前；
2. Provider 返回媒体后；
3. 正式导出前。

对拒绝内容：

- 标记具体文本或镜头；
- 提供安全改写建议；
- 不通过换 Provider 无限绕过限制；
- 保留合规审计事件，但避免存储不必要的敏感原文副本。

## 8. 剪映兼容与合规

- 不修改用户现有草稿；
- 不绕过签名、授权、付费素材或访问控制；
- 使用用户合法安装的目标版本做兼容验证；
- 在发布适配器前审查剪映许可与 EULA；
- 明确支持版本和限制；
- 始终提供通用媒体包降级出口。

## 9. 可靠性风险

### 应用崩溃或断电

使用 SQLite WAL、原子文件移动、任务租约和启动恢复扫描。

### 外部 API 已成功但本地超时

先查询 provider job ID，不能直接重复提交，以免重复扣费。

### 数据库与文件不一致

- 文件落盘并校验后再提交资产记录；
- 使用临时文件 + 原子改名；
- 周期执行引用完整性扫描；
- 不自动删除被版本引用的文件。

### 磁盘不足

生成和导出前估算空间；阈值预警；提供安全缓存清理器。

## 10. 审计

记录：

- 项目设置变化；
- 圣经/剧本/分镜批准；
- 模型调用；
- 重试和路由切换；
- 成本调整；
- 资产删除；
- 导出；
- 声音/肖像授权状态变化。

审计日志仅追加，并允许用户导出项目报告。
