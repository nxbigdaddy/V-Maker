# V-Maker 设计文档

V-Maker 是一套面向 AI 动画生产的 GUI 软件构想。用户输入单集或多集故事，系统把故事逐步转换为项目圣经、分集大纲、剧本、分镜、关键帧、视频、配音、音乐与字幕，最终输出合成成片，或输出可继续编辑的剪映草稿。

## 设计目标

- **前台简单**：用户可以只输入故事和少量偏好。
- **后台可控**：所有创作步骤结构化、可追踪、可重试、可局部修改。
- **模型可替换**：DeepSeek、Qwen Image、H3、TTS 等通过 Provider 接口接入。
- **单集与系列兼容**：系列项目共享角色、场景、道具、声音和风格资产。
- **两种交付方式**：确定性合成 MP4；可编辑时间线/剪映草稿。
- **渐进自动化**：支持全自动、关键节点确认和专业逐步审核三种模式。

## 产品的一句话定义

> 一个以“镜头”为最小生产单元、以“项目圣经”为一致性来源、以任务 DAG 为执行核心的 AI 动画导演与制作工作台。

## 建议首版形态

建议优先实现 **本地桌面应用 + 本地后台服务 + 云端模型 API**：

- 桌面 GUI 负责项目管理、审阅和编辑；
- 本地后台负责任务编排、素材管理、FFmpeg 合成和导出；
- 云端 API 负责 LLM、生图、生视频和语音；
- 项目文件和密钥默认保存在本地；
- 后续可把后台替换为团队服务器，但不改变核心数据协议。

## 核心原则

1. 不把一部长故事一次性交给视频模型。
2. LLM 负责规划和产生结构化决策，确定性程序负责执行与验证。
3. 每个生成物都关联来源、模型、参数、提示词、版本和成本。
4. 修改角色圣经时，系统必须显示受影响的镜头，而不是默默全量重生。
5. 高成本生成前必须先有低成本动态分镜。
6. 剪映草稿是适配器输出，不应成为内部唯一时间线格式。
